# X-Music

一个基于 Flutter 开发的网易云音乐第三方客户端。
小项目，不喜勿喷，有问题欢迎在 [issue](https://github.com/hoadl114514/X-Music/issues) 指出。

> 当前版本：v0.1.5。已接入网易云接口和真实播放。目前只做手机端（Android + iOS）。
>
> Releases 只提供 Android APK。iOS 暂无安装包，需要自己用 Xcode 构建。
>
> 第三方客户端，与网易云音乐官方无关。

## 下载

到 [Releases](https://github.com/hoadl114514/X-Music/releases) 下载 APK。大多数手机选 `arm64-v8a`，不确定就选 `universal`。

## 运行

需要 Flutter 3.47+（Dart 3.13+）。

```bash
flutter pub get
flutter run              # 连接 Android / iOS 设备或模拟器
```

构建正式签名的 APK：在 `android/` 下新建 `key.properties`（已被 `.gitignore` 忽略），写入 `storeFile`、`storePassword`、`keyAlias`、`keyPassword`，再运行 `flutter build apk --release`。没有这个文件时 release 包退回 debug 签名，只适合本地调试。

`web/` 目录只用于在浏览器里快速预览界面，不是发布目标（QQ 歌词解密依赖 64 位整数，Web 上不可用）。

## 已实现

- **登录**：扫码（用网易云 App 扫一扫）或粘贴 Cookie（需要包含 `MUSIC_U`，只保存在本机）。未登录也能搜索、播放免费歌曲的标准音质。
- **搜索**：单曲 / 歌单 / 歌手 / 专辑，输入时联想，滚到底自动翻页；保留最近 20 条搜索历史（可单条删除或清空）。
- **首页 / 发现**：首页有每日推荐、我喜欢、私人 FM、「根据你喜爱的歌曲推荐」（每列 3 首横向翻页，可换一批，正在放的那首按钮变成暂停）、雷达歌单、推荐歌单；「发现」页分歌单广场（选分类，推荐 / 精品）、排行榜、最新音乐三个标签。私人 FM 可以点「不喜欢」，之后不再推荐并跳到下一首；放到倒数第二首就提前取下一批；可以选模式（推荐、熟悉、探索、AI DJ、运动、专注、深夜）。
- **最新音乐**：「发现」里的第三个标签，按全部 / 华语 / 欧美 / 日本 / 韩国列出最近一周的新歌。
- **音乐库**：底部「音乐库」有我喜欢的音乐，最近播放、听歌排行、关注的艺人三个入口，创建的歌单、共享歌单、收藏的歌单，切回来时后台刷新；点歌开始播放整张歌单。歌单没有封面或封面加载失败时，用第一首歌的封面。
- **共享歌单**：新建时可选共享歌单。歌单名下面显示成员头像和「管理」：查看成员、分享邀请链接、移出成员、协作者退出。每首歌下面显示是谁添加的；协作者也能加歌、删歌。
- **歌单管理**：音乐库里「新建」创建歌单，可设为隐私歌单（只有自己能看到）。自己的歌单在「⋮」里改名称、简介、封面、分享或删除；收藏的歌单在「⋮」里取消收藏。
- **歌曲菜单**：歌曲列表每行右侧「⋮」：下一首播放、喜欢、收藏到歌单、分享链接、查看歌手、查看专辑。自己的歌单和「我喜欢」里多一项「从歌单中删除」，也能多选批量删除。
- **播放**：just_audio；通知栏、锁屏、耳机和蓝牙按键都能控制，通知栏带喜欢按钮；上一首 / 下一首、随机、单曲循环（播放模式会记住，重启后沿用）、播放队列、拖动进度、定时关闭（预设时长或自定义小时 / 分钟）。无版权的歌自动跳过；只能试听时提示，歌词时间自动换算。
- **音频输出**：设置里可以选移动网络播放音质、输出通道（Android 音频输出设备）、输出位深（16 / 24 位整数、32 位浮点）、输出采样率，以及 USB DAC 独占模式（Android 14 起）。
- **音质**：只显示当前歌曲实际提供的档位（标准 → 超清母带共 9 档，来自 `song/music/detail/get`）。选中的档位同时设为默认；歌曲没有该档时自动选它有的最高档，账号权益不足时服务端降级并提示。
- **歌词**：三个来源，网易云（YRC 逐字 / LRC 逐行）、QQ 音乐（QRC 逐字，客户端解密）和 [AMLL Hub](https://beta.amllhub.bikonoo.com/) 社区歌词库（TTML 逐字，按网易云歌曲 id 精确对应；支持背景人声（唱到时浮现、唱完收起）、对唱靠右、注音、不雅用语屏蔽、歌曲段落，自身没有罗马音时用网易云的）。各来源同时请求，按顺序取第一个有歌词的。都带翻译和罗马音（有就显示，可开关）。按设置里「歌词来源」排的顺序依次获取（默认网易云 → AMLL → QQ，可拖动调整，也可关闭某个来源）；播放页「更多」里可以手动切换来源、调整歌词偏移。QQ 歌词按标题、歌手、时长、版本（Live / 伴奏 / Remix…）保守匹配，拿不准就不用。
- **喜欢**：红心同步到网易云账号。
- **用户主页**：歌手和绑定的账号合在一起显示。主页有 TA 的热门作品、音乐品味（听歌排行、喜欢的音乐）、创建 / 收藏的歌单（各显示前三，可查看全部）；有发行作品的再加「全部歌曲」（热度 / 最新）和「专辑」（可搜索）；头部可以关注 / 取消关注（歌手走 `artist/sub`），点关注数 / 粉丝数看列表。从歌单创建者、抽屉个人资料、歌手名进入。搜索页的「用户」结果还没做（代码里标了 `TODO(用户主页)`）。
- **用户状态**：用户主页名字下面显示 TA 当前的状态（例如「学习中」），状态带歌时点一下播放。在自己的主页可以从官方提供的状态里选一个，可编辑的状态能自己写文字；还能看「和我状态相同的人」。接口参考 api-enhanced 的 `user/social/status*`，需要登录。
- **听歌缓存**：听过的歌按当前音质边播边存到本机，再听不耗流量；封面、歌词、音质信息（含位深）、账号、歌单列表、最近播放和听歌排行也一起缓存，进页面先显示缓存，后台再取最新的，断网也能看音乐库。设置里可以调缓存上限（歌曲、图片、数据合计）、清空缓存。
- **看图**：长按封面、头像进入看图页，可缩放，长按保存到相册。
- **列表内搜索**：歌单、我喜欢、专辑、歌手等歌曲列表都能搜索列表内的歌曲。
- **最近播放同步**：登录后开始放一首歌就报给网易云，出现在官方客户端的「最近播放」；听满 30 秒（短歌听一半）再给听歌排行计数。走和官方客户端一样的日志接口（EAPI + clientlog 域名）；设置里可以关掉。
- **检查更新**：启动时查 GitHub 最新正式版，比当前版本新就弹窗，可以去下载、以后再说或跳过此版本。设置页「关于」点一下打开项目主页。
- **复制**：长按歌词复制这一句，或进入批量选择（点选单句、长按选一段、全选，可带翻译 / 罗马音）；长按歌名 / 歌手选择复制歌名、歌手、专辑或「歌名 - 歌手」；也可以进入「自由复制」，选任意一段文字复制。

## 设计

- 手机端布局：顶栏（大标题 + 右上角「⋮」菜单：设置、账户）+ 内容 + 悬浮的迷你播放条 + 悬浮胶囊底栏；底栏是首页 / 发现 / 搜索 / 音乐库。
- **一起听**：开房间或粘贴邀请链接加入，好友用官方客户端也能互通。双方谁切歌、暂停、拖进度都会同步：本地操作上报为指令，每 2 秒拉一次房间快照（`sync/playlist/get` 的 `playCommand`），按指令进度加上服务器收到指令后过去的时间推算当前进度（做法参考 Enji、MeloX-Android）。从播放页「更多」进入；在房间里时，播放页底部有一起听管理条，迷你播放条左上角显示一起听的成员头像。
- 这一版是纯听歌：评论、动态、私信、听歌状态都去掉了。
- 暗色、无彩界面，颜色交给封面；唯一强调色是樱花粉 `#F5A3C7`，只用在选中、喜欢、进度等功能性位置。
- 播放页：背景是封面主色的纯色渐变；中间是大封面，左滑看歌词，右滑看歌曲百科（曲风、标签、语种、BPM、获奖，「喜欢这首歌的人也爱听」，关于艺人，相关歌单）。播放控制只在封面页显示；百科页和歌词页的标题旁换成上一首 / 播放 / 下一首。音质列表显示码率、采样率、位深和大小。
- 全屏歌词：封面主色做底，已唱的行偏白、未唱的行压暗，当前行逐字填色，附翻译和罗马音；当前行逐帧平滑滚动（上一句没唱完不跳到下一句），手动滚动后暂停跟随 3 秒；间奏 5 秒以上时浮出三个点，按间奏时长均匀消失；「更多」里可调歌词偏移。

## 目录

```
lib/
  app/        应用入口、显示名与版本、服务装配（AppServices）、检查更新
  api/        网易云接口（EAPI 加解密、Cookie）
  audio/      播放内核接口 + just_audio 实现、系统媒体控制、听歌缓存
  lyrics/     歌词解析（LRC / YRC / QRC / TTML）、QQ 歌词搜索匹配与解密、AMLL 歌词、歌词来源调度
  theme/      颜色、圆角、阴影、ThemeData
  data/       模型、格式化工具
  state/      播放器、账号、本地设置
  shell/      主框架：顶栏、抽屉侧栏、迷你播放条、底部导航
  pages/      首页、搜索、登录、设置，以及 library（歌单）、music（发现 / 歌手 / 专辑 / 排行）、
              now_playing（播放页 / 歌词）、social（关注列表）、user（用户主页）
  widgets/    通用组件（封面、主色提取、歌曲行、红心、待开发标签）
```
